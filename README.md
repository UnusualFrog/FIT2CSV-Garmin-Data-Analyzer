
# Fit2CSV-Workout-Data-Analyzer


A tool for aggregating, preprocessing, and visualizing fitness data (.FIT files) generated by GPS-based fitness devices such as Garmin smart watches and Zwift bicycle sensors. Data is concatenated into a singular CSV file for easy data analysis, including several built-in graphs generated using matplotlib.

## Installation


```bash
  git clone https://github.com/UnusualFrog/FIT2CSV-Garmin-Data-Analyzer
  cd FIT2CSV-Garmin-Data-Analyzer
```
    
## Usage
In order to use this tool, Garmin data is required. This tool is built for analysis of Garmin FIT file data. Find out how to extract data from your device using the following link https://support.garmin.com/en-IN/?faq=W1TvTPW8JZ6LfJSfK512Q8

Once your .FIT files have been acquired place them in the `/input` directory in the project and run main.py with the following command

```
python main.py
```

This will produce two things:

    1. output/csv/output.csv - an aggregation of all FIT files included in the input
    2. output/graph - 3 graphs generated in MatPlotLib tracking various monthly/annual metrics based on output.csv

NOTE: if not .FIT files are found in the `/input` directory, the program will fallback to the example file `activities.zip` which will demonstrate the tool using example .FIT activity data.
