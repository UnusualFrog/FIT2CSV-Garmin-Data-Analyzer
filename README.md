
# Fit2CSV-Workout-Data-Analyzer


A tool for aggregating, preprocessing and concatenating fitness data (.FIT files) generated by GPS-based fitness devices such as Garmin smart watches and Zwift bicycle sensors into a singular CSV file for easy data analysis with Pandas and MatPlotLib.

## Installation

Install my-project with npm

```bash
  git clone
  cd my-project
```

  return <Component />
